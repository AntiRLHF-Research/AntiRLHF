### 创建聚焦的子任务

每个 Agent 收到：
- **明确范围：** 一项独立责任及其契约影响的调用方。
- **清晰目标：** 通过真实入口完成要求的行为。
- **约束：** 遵守授权范围并保留其他工作；共享所有者的修改统一协调。
- **预期输出：** 已实现的结果、发生变化的消费者契约及剩余阻塞。

## 子代理提示词结构

好的子代理提示词应当：
1. **聚焦：** 一个清楚的问题领域。
2. **自包含：** 包含理解问题所需的全部上下文。
3. **输出明确：** 说明 Agent 应返回的内容。

## 不适合使用的情况

**相关故障：** 修复一个可能同时修复其他问题，先合并调查。
**需要完整上下文：** 理解问题需要看到整个系统。
**探索性调试：** 还没找到发生故障的部分。
**共享状态：** 多个 Agent 会相互干扰，例如编辑相同文件或使用相同资源。
