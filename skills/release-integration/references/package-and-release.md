# 包和发布环境

## 包内容属于功能

从用户的安装命令开始确认分发文件、依赖、资源和入口。源码路径可运行而安装包缺资源时，修复打包配置。插件发现路径、数据库迁移文件、国际化资源和平台二进制属于实际发布行为。

优先使用项目的包管理器、构建工具和平台发布能力。内容、版本与说明来自当前实现，不另建平行的手写清单维护同一事实。

## 持久数据与公开契约

正式环境已有数据时，明确迁移输入、转换规则、写入顺序和失败后状态。数据迁移需要的备份或恢复按实际风险安排。开发期可丢弃数据由用户确认后重建；内部模型同步替换，不长期保留多版读取器。

公开客户端在真实支持期内保留对外契约，内部统一当前模型。发布节奏确实分批时再设计过渡路径和结束条件。

## 失败与恢复

构建失败先定位具体产物；上传失败保留本地产物；部署失败根据平台真实状态选择重试、回滚或停止。不要为每种想象失败写多层恢复系统。

确认当前版本是否已对外生效，按实际结果向用户说明。授权工作完成后结束；未来优化作为新的任务处理。
