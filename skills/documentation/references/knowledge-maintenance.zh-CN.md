# 单一事实来源与持续维护的项目知识

为每项维护中的事实找到责任来源。配置、行为说明、真实实现、观察证据、历史发布可以拥有不同维护所有者。其他位置通过引用、生成或明确同步关系复用。发生冲突时回到实际需求，修正出错的责任文件及其消费者。

入口负责用途和导航；现行指南说明当前行为；研究笔记保存资料、观察与假设；发布历史记录过去真实发生的事件。只有存在独立长期维护职责时才新建专题文件，不因一次纠错建立完整目录分类或长期台账。

删除废弃术语或功能时，直接改写现行说明，清理失效锚点和派生产物，真实发布史保留在自身位置。不要把一次修正写成影响所有后续文稿的永久禁令。同步受同一事实影响的有效翻译和示例。

事故确实能够改变未来可复用的行动时才纳入持久 Agent 指令；优先修正既有责任文件。临时会话日志留在任务自身状态中。
