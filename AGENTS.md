# Repository instructions

This repository is the paper-experiment copy of AntiRLHF. It is treatment material for `task-aware-governance-experiments`.

- The agent under study may receive `CONSTITUTION.md` and the five core skills under `skills/`. Add `project-workflows` only for an explicit setup, CI, or release task.
- `docs/`, `archive/`, and the root README, INSTALL, and this file stay with the researchers.
- Read `CONSTITUTION.md` before changing the skill text.
- Use `skills/antirlhf-plan` for changes to the method's judgment and structure.
- Use `skills/antirlhf-exec` for changes to the skill files themselves.
- Treat `archive/` as historical material. It does not define the current experiment skill.
- Do not add a second governance framework, a compatibility layer, or the old `ai-agent-governance` entry points beside this bundle.
- `scripts/install.py` installs into the task environment chosen by the experiment runner.
