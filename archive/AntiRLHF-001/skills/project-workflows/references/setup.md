# Integrate Skills into a project

Identify the actual harness, its discoverable skill directories, active project instructions, and the user's intended scope. Reuse its native Skill mechanism and currently supported locations. Install the selected full skill directories together when they refer to siblings, and install the Constitution in the persistent instruction location the user has authorized.

Inspect existing project instructions before editing. Preserve real project-specific commands and requirements; replace contradictory or superseded boilerplate in its own location. If the user requests a project entrypoint, give it only the few project-specific facts and links the executing agent needs. Do not copy the Constitution into each skill or repository file.

Check the target discovery path and at least one actual linked reference with the chosen harness. Make relevant fixes to the source owner; do not introduce a compatibility alias for an imagined harness version. End after the requested integration works.
